# Gestor Financeiro

O Gestor Financeiro é uma página para acompanhar as finanças pessoais do mês. Ela mostra o saldo atual, o total de entradas e saídas e quanto da renda mensal já foi gasto. A listagem principal traz as transações do mês (descrição, categoria, data e valor), que podem ser filtradas entre entradas e saídas. A listagem secundária mostra as metas de economia, cada uma com o valor guardado, o valor que falta e o prazo. Também há um relatório do mês com os gastos por categoria e os maiores gastos.

Projeto desenvolvido no Trabalho de Conclusão da Disciplina de Desenvolvimento de Aplicações Web, com React, TypeScript e Tailwind CSS.
